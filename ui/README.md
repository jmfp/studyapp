# UI References

These images are design references for the FlashStudy app UI.

## Design Language
- Dark backgrounds (#0D0D0D, #1A1A2E, #16213E)
- Purple accent (#6C63FF, #7C3AED)
- Neon green accents for analytics (#B2FF59, #76FF03)
- White cards with subtle shadows
- Rounded corners (16-24px border radius)
- Clean typography, generous spacing
- Bottom tab navigation (dark pill style)
- Card-based layout throughout

## Color Palette
- Primary: #6C63FF (Purple)
- Background Dark: #0F0F1A
- Surface: #1C1C2E
- Accent Green: #B2FF59
- Text Primary: #FFFFFF
- Text Secondary: #A0A0B0
- Success: #4CAF50
- Error: #FF5252

## Key UI Patterns (from references)
1. Dark mode with purple/violet primary actions
2. Pill-shaped bottom tab bar with active state highlight
3. Progress bars for topic completion
4. Analytics with line graphs, circular progress indicators
5. Calendar heatmap for study streaks
6. Card-based lists with images/icons
7. Large bold headings
8. Stats counters (students, reviews, progress %)
